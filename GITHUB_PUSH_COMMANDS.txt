TROUBLESHOOTING
───────────────

❌ Error: "Authentication failed"
✓ Solution: GitHub requires a personal access token now
  1. Go to https://github.com/settings/tokens
  2. Create new token with repo access
  3. Use token instead of password when prompted

❌ Error: "fatal: 'origin' does not appear to be a git repository"
✓ Solution: Check you're in the correct directory
  cd "g:\AliPortfolio\New folder"
  git status

❌ Error: "ref does not match any existing object"
✓ Solution: Main branch exists. This error usually means the command is fine.
  Try again: git push -u origin main --tags

❌ Need to undo the remote?
✓ Solution: git remote remove origin
  Then re-add with correct URL
